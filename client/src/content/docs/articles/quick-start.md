## Before you begin

Have access to the Instagram professional account you intend to connect and a clear example of the audience action you want to respond to. Start with one simple use case instead of automating every conversation at once.

## 1. Connect Instagram

From the signed-in dashboard, open the Instagram connection flow and complete Meta authorization.

1. Open **Integrations** from the dashboard.
2. Start the Instagram connection and complete the authorization prompts.
3. Return to SignalAI and confirm that the account is shown as connected and healthy.

The public connection-error page is not the place to start a new connection; initiate the flow from the dashboard.

## 2. Create an automation draft

1. Open **Automation**.
2. Choose **Start from a template** for a guided starting point, or choose **Create draft** for a blank automation.
3. Give it a name that describes the business outcome, such as Property Enquiry or Course Details.
4. Configure the trigger keywords and channel for the use case.
5. Open the draft in **Flow** to continue configuring it.

A draft does not reply to Instagram conversations until it has been published and activated.

## 3. Configure the flow and reply

Use **Setup** for the automation's trigger, reply mode, targeting, and other configuration. Use **Flow** to inspect and edit the conversation path. Choose AI-generated or Rule-based reply mode, write the default reply, and select the reply channel.

## 4. Add a qualification goal

In Flow, add a goal with a clear description. Add only the fields your team genuinely needs, such as location and buying intent. A goal should represent a useful checkpoint, not a long questionnaire.

## 5. Preview, test, and publish

Use **Preview** to inspect a reply to sample text. Use **Sample walkthrough** to exercise the trigger, reply, and goal sequence; it does not create a real lead.

1. Save your changes explicitly when the Flow shows unsaved work.
2. Confirm the Flow shows a saved state and the intended version has loaded.
3. Choose **Publish** and review the version confirmation.
4. Activate the automation only after its readiness checks pass.

## 6. Verify the real flow

Use a separate Instagram account to exercise the actual trigger. Check that the incoming activity and reply appear in Inbox. Confirm that the prospect appears in Leads when the configured qualification flow produces a lead.

## Best practices

- Use one automation for one clear campaign or audience intent.
- Test both a matching keyword and a message that should not match.
- Keep the opening reply short and easy to understand.
- Capture the minimum useful fields; don't make the first message feel like a form.
- Run a real Instagram test after Preview and Sample walkthrough, because simulations do not verify delivery.

## If something does not work

Check the stages in order: account connection → incoming event in Inbox → trigger match → reply behavior → qualification goal → lead record. Troubleshooting explains how to isolate the failing stage.
